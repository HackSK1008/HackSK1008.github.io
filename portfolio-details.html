About the Project

FitMantra is an AI-powered virtual gym trainer that democratises access to quality fitness guidance by replacing expensive personal trainers with a real-time, computer vision–based coaching system. Built with a team of 7 as Team Leader and Computer Vision Engineer, FitMantra combines pose estimation, gamification, and IoT sensor integration to deliver personalised, data-driven fitness experiences.

The system uses OpenCV and MediaPipe for real-time body landmark detection, feeding into a TensorFlow-based classification model that analyses posture angles and identifies form errors with immediate audio-visual feedback. This pipeline achieved a ~60% reduction in posture errors during testing — a measurable, clinically meaningful outcome for injury prevention.

FitMantra earned 1st Prize in the Healthcare Domain at an International Hackathon hosted by PICT Pune, and was subsequently published as an Indian Patent (Application No. 202421004780, Feb 2024) — validating the technical originality and commercial potential of the solution.

Technical Architecture

Input Layer

Live video capture → MediaPipe Pose → 33 body landmark extraction at 30fps

Analysis Layer

Joint angle computation → TensorFlow classifier → posture error detection with confidence scoring

Output Layer

Real-time visual overlay + audio cues → gamification engine → server-side analytics dashboard
